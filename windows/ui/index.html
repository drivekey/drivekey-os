How the software protects your approvals

Local vaults use AES-256-GCM encryption and scrypt key derivation. Signing runs in short-lived workers. Reviewed transactions are checked before signing, and saved responses support recovery.

Encrypted recovery storage uses Windows DPAPI. The same user account or a compromised computer remains a security boundary. This is a software wallet; physical isolation and independent certification are not established by these checks.
